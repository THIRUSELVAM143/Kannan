# PanelForm

A mobile-first website for fibre cement panel construction services in Erode, Tamil Nadu.

## Run locally

```sh
npm install
npm start
```

## Verify and build

```sh
npm test -- --watchAll=false
npm run build
```

## Before publishing

- Replace the provisional `PanelForm` brand and the bracketed phone, email and address values in `src/App.js`.
- Connect the contact form to an inbox or form service. It currently validates the fields and explains that it does not submit or upload files.
- Replace `www.example.com` in `public/sitemap.xml` and add the production sitemap URL to `public/robots.txt`.
- Update the LocalBusiness name in `public/index.html` to match the business.
- Project photos are optimized JPEGs in `public/images/`; their originals are in `src/WhatsApp Unknown 2026-11-16 at 7.11.50 AM/`.
